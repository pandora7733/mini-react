# Cyberpunk 2077 디자인 가이드

mini-react 예시 앱(가계부, Focus Board, Diff 검증 페이지)에 입힐 사이버펑크 테마의 기준 문서입니다. 게임 *Cyberpunk 2077*의 분위기를 참고했습니다. 이 가이드의 색, 서체, 형태는 모두 이 프로젝트를 위해 새로 정한 값입니다.

> **저작권 주의.** *Cyberpunk 2077*은 CD PROJEKT RED의 상표입니다. 공식 로고, 게임 아트, 캐릭터, 공식 서체, 게임 화면 캡처, 기업명(Arasaka, Militech 등)은 쓰지 않습니다. 참고하는 것은 장르의 분위기뿐이고, 이 프로젝트는 게임과 관계가 없습니다.

## 1. 디자인 원칙

1. **도시의 단말기처럼.** 화면은 길거리 단말기의 HUD처럼 보이게 합니다. 정보는 촘촘하게 넣되 정렬은 엄격하게 맞춥니다.
2. **노란색은 신호에만.** 시그널 옐로는 "지금 눌러야 할 것"과 "방금 바뀐 것"에만 씁니다. 장식으로 칠하지 않습니다.
3. **모서리는 깎는다.** 둥근 모서리 대신 한쪽 귀퉁이를 사선으로 자릅니다. 이 형태가 테마를 드러내는 핵심 장치입니다.
4. **과장은 한 군데만.** 글리치나 네온 번짐 같은 큰 효과는 한 화면에 하나만 둡니다. 나머지는 조용하게 둡니다.
5. **읽기가 먼저.** 분위기 때문에 숫자나 글을 읽기 어려워지면 안 됩니다. 가계부 금액은 이 테마에서도 가장 읽기 쉬운 요소여야 합니다.

## 2. 색

`styles.css`의 기존 변수 이름을 그대로 유지하고 값만 바꿉니다. 테마를 바꿔도 컴포넌트 CSS는 수정할 필요가 없습니다.

### 다크 (기본: 밤의 도시)

| 변수 | 값 | 이름 | 쓰임 |
|---|---|---|---|
| `--bg` | `#0c0d12` | 아스팔트 | 페이지 배경 |
| `--surface` | `#15171f` | 단말기 | 패널, 카드, 입력창 |
| `--text` | `#e9ecf2` | 형광등 | 본문 |
| `--muted` | `#8b93a7` | 매연 | 보조 정보, 라벨 |
| `--border` | `#2a2e3b` | 철판 | 경계선 |
| `--accent` | `#f3e600` | 시그널 옐로 | 주요 버튼, 선택 상태, 포커스 |
| `--accent-text` | `#0c0d12` | — | 노란 바탕 위 글자 |
| `--danger` | `#ff3b5c` | 경보 레드 | 지출, 삭제, 오류 |
| `--flash` | `rgba(0, 229, 255, 0.35)` | 데이터 시안 | DOM 변경 하이라이트 |

새로 추가하는 변수:

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--info` | `#00e5ff` | 수입, 링크, 데이터 강조 |
| `--glow` | `0 0 12px rgba(243, 230, 0, 0.45)` | 노란 요소의 네온 번짐 (활성 상태에만) |

### 라이트 (낮의 경고판)

라이트 모드는 하얀 배경 대신 **노란 경고판**입니다. 노란 바탕에 검은 글씨를 씁니다.

| 변수 | 값 |
|---|---|
| `--bg` | `#f3e600` |
| `--surface` | `#fff8a6` |
| `--text` | `#111216` |
| `--muted` | `#4d4818` |
| `--border` | `#111216` |
| `--accent` | `#111216` |
| `--accent-text` | `#f3e600` |
| `--danger` | `#b0002a` |
| `--info` | `#00606e` |
| `--flash` | `rgba(0, 96, 110, 0.3)` |

### 대비 기준

- 본문(`--text`)과 보조 정보(`--muted`)는 배경 대비 4.5:1 이상을 유지합니다.
- 시안과 레드를 작은 글자에 쓸 때도 같은 기준을 지킵니다. 위 값은 두 모드 모두 이 기준을 만족하도록 골랐습니다.
- 수입과 지출을 색으로만 구분하지 않습니다. `+`, `−` 부호를 항상 함께 표시합니다.

## 3. 타이포그래피

| 역할 | 서체 | 이유 |
|---|---|---|
| 제목, 숫자 | **Chakra Petch** (Google Fonts) | 각진 획이 깎은 모서리 형태와 어울림 |
| 한글 본문 | **IBM Plex Sans KR** (Google Fonts) | 기계적인 인상을 유지하면서 한글 가독성이 좋음 |
| 코드, 패치 로그 | **JetBrains Mono** | Phase 1 패치 내역, Diff 출력 |

```css
@import url("https://fonts.googleapis.com/css2?family=Chakra+Petch:wght@500;700&family=IBM+Plex+Sans+KR:wght@400;600&family=JetBrains+Mono:wght@400&display=swap");

body {
  font: 16px/1.65 "IBM Plex Sans KR", system-ui, sans-serif;
}

h1, h2, h3, .amount {
  font-family: "Chakra Petch", "IBM Plex Sans KR", sans-serif;
  letter-spacing: 0.02em;
}

.amount {
  font-variant-numeric: tabular-nums;
}
```

**크기 단계:** 13 / 16 / 20 / 28 / 40px. 한 화면에서 쓰는 크기는 네 가지를 넘기지 않습니다.

**규칙**
- 금액은 `tabular-nums`로 자릿수를 맞춰 세로로 정렬합니다.
- 제목 안의 한 단어만 색을 바꾸는 식의 강조는 하지 않습니다. 강조가 필요하면 제목 전체의 크기나 굵기로 처리합니다.
- 모든 라벨을 대문자로 쓰지 않습니다. 대문자는 상태 배지(`LIVE`, `ERR`)처럼 짧은 기호에만 씁니다.
- 한 줄은 80자 이하로 유지합니다.

## 4. 형태

### 깎은 모서리

테마를 드러내는 핵심 장치입니다. 오른쪽 아래 귀퉁이만 깎습니다.

```css
:root {
  --cut: 12px;
}

.panel,
button.primary {
  clip-path: polygon(
    0 0,
    100% 0,
    100% calc(100% - var(--cut)),
    calc(100% - var(--cut)) 100%,
    0 100%
  );
}
```

- `clip-path`를 쓰면 `border`도 잘립니다. 경계선이 필요한 패널은 바깥 요소를 `--border` 색으로 칠하고 안쪽 요소를 1px 작게 겹치는 방식으로 만듭니다.
- 버튼은 `--cut: 8px`, 패널은 `12px`, 페이지 단위 컨테이너는 `20px`입니다. 크기가 위계를 나타냅니다.
- `border-radius`는 쓰지 않습니다. 체크박스와 라디오 버튼만 예외입니다.

### 간격

4px 단위를 씁니다: 4 / 8 / 12 / 16 / 24 / 40.

## 5. 효과

| 효과 | 어디에 | 규칙 |
|---|---|---|
| 네온 번짐 (`--glow`) | 활성 버튼, 포커스된 입력창 | 상시 켜두지 않음. 상태가 바뀔 때만 |
| 스캔라인 | 페이지 배경 전체 | 불투명도 4% 이하, 글자 위에는 겹치지 않음 |
| 글리치 | 페이지 첫 진입 시 `h1` 한 번 | 400ms 이하, 한 번만 재생 |
| DOM 변경 하이라이트 | Phase 2의 변경 표시 | 기존 `--flash`를 시안으로 바꿈 |

```css
body::before {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  background: repeating-linear-gradient(
    to bottom,
    transparent 0 2px,
    rgba(255, 255, 255, 0.03) 2px 3px
  );
  z-index: -1;
}

@keyframes glitch {
  0%   { transform: translate(0); clip-path: inset(0 0 0 0); }
  30%  { transform: translate(-2px, 1px); clip-path: inset(10% 0 60% 0); }
  60%  { transform: translate(2px, -1px); clip-path: inset(50% 0 20% 0); }
  100% { transform: translate(0); clip-path: inset(0 0 0 0); }
}

h1.enter {
  animation: glitch 360ms steps(3) 1;
}

@media (prefers-reduced-motion: reduce) {
  h1.enter { animation: none; }
}
```

## 6. 컴포넌트

### 버튼

| 종류 | 모양 |
|---|---|
| 주요 (`.primary`) | 노란 바탕, 어두운 글자, 깎은 모서리 8px. 호버 시 `--glow` |
| 보조 | 투명 바탕, 1px `--border` 테두리. 호버 시 테두리만 노란색 |
| 위험 | 투명 바탕, `--danger` 글자와 테두리 |

버튼 글자는 눌렀을 때 일어나는 일을 그대로 씁니다. 예: "지출 추가", "삭제". 누른 뒤의 알림도 같은 단어를 씁니다. 예: "지출을 추가했습니다".

### 입력창

- 바탕은 `--surface`, 아래쪽 테두리만 2px로 그립니다.
- 포커스되면 아래쪽 테두리가 `--accent`로 바뀌고 `--glow`가 붙습니다.
- 오류가 나면 테두리를 `--danger`로 바꾸고, 바로 아래에 무엇이 잘못됐고 어떻게 고치는지 한 줄로 적습니다.

### 패널

- 왼쪽 위에 3px × 24px 노란 막대를 붙여 패널의 시작을 표시합니다.
- 패널 제목은 `h2`(20px, Chakra Petch)를 씁니다. 제목 위에 별도 라벨을 달지 않습니다.

### 표 (가계부 내역)

- 줄무늬 배경을 쓰지 않습니다. 행 사이에 1px `--border` 선만 긋습니다.
- 금액 열은 오른쪽으로 정렬하고 `tabular-nums`를 적용합니다.
- 지출은 `--danger`와 `−`, 수입은 `--info`와 `+`로 표시합니다.

### 내비게이션 (`Link`)

- 현재 라우트의 링크는 아래쪽에 노란 2px 막대를 붙이고 글자를 `--text`로 표시합니다.
- 나머지 링크는 `--muted`로 표시합니다.

## 8. 하지 않을 것

- 공식 로고, 게임 이미지, 공식 서체, 게임 속 기업명 사용
- 화면 여러 곳에 동시에 네온 번짐이나 글리치 적용
- 모든 카드를 같은 모양과 같은 그림자로 반복 배치
- 노란색을 배경 장식이나 구분선 용도로 사용 (라이트 모드의 페이지 배경은 예외)
- 순수 장식용 번호(01 / 02 / 03). 실제 순서가 있는 내용에만 번호를 붙임
