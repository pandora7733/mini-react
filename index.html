mini-react

Virtual DOM, Diff, Patch, Component, Hooks를 의존성 없이 TypeScript로 직접 구현했습니다.

Phase 1. Diff 검증 페이지 HTML을 고치고 Patch를 누르면 바뀐 부분만 실제 영역에 반영됩니다. 뒤로가기와 앞으로가기를 지원합니다. Phase 2. Focus Board 루트 컴포넌트에만 상태를 둔 할 일 보드입니다. 갱신마다 실제 DOM 변경 수를 보여 줍니다. 예시 앱. 가계부 자식 컴포넌트의 자체 상태, 커스텀 훅, SVG 차트까지 mini-react만으로 만든 앱입니다. 브라우저 테스트 DOM이 필요한 단위 테스트와 두 페이지의 기능 테스트를 실행합니다.
